# iShweather User Manual

iShweather is a weather forecast app for iPhone that provides 10-day daily and 72-hour hourly forecasts for any location.

---

## Getting Started

When you open iShweather for the first time, you'll see an empty forecast screen with a search bar at the top. You need to search for a location before any forecast is displayed.

---

## Searching for a Location

1. Tap the **search bar** at the top of the screen (it shows "Search location…").
2. Start typing a city, town, or address. Suggestions will appear below the search bar as you type.
3. Tap a suggestion to select it. The forecast for that location will load automatically.

To clear the search and start over, tap the **✕** button on the right side of the search bar.

---

## Recent Locations

iShweather remembers up to 15 locations you've previously searched for.

To access your recent locations:

1. Tap the **clock icon** on the right side of the search bar (visible when the search bar is empty).
2. A list of your recent locations appears below the search bar.
3. Tap any location in the list to load its forecast immediately.

Your recent locations and your last-viewed location are saved automatically and restored the next time you open the app.

---

## Switching Between Daily and Hourly Forecasts

Use the **segmented control** below the search bar to switch views:

- **10-Day** — shows a daily forecast for the next 10 days.
- **Hourly** — shows an hour-by-hour forecast for the next 72 hours.

Your preferred view is remembered between sessions.

---

## Reading the Daily Forecast

Each row in the 10-day forecast shows:

| Column | Description |
|---|---|
| Day | Day of the week (today's row shows "Today") |
| Icon | Weather condition symbol |
| Condition | Brief description (e.g., "Partly Cloudy") |
| Precipitation | Chance of rain or snow (shown as a percentage with a raindrop icon) |
| High / Low | Daily high and low temperatures in °F |

### Expanded Daily Details

Tap any row to expand it and reveal additional detail:

| Detail | Description |
|---|---|
| Humidity | Relative humidity percentage |
| UV Index | Ultraviolet index (0 = minimal, 11+ = extreme) |
| Sunrise | Time of sunrise |
| Sunset | Time of sunset |

Tap the row again to collapse the details.

---

## Reading the Hourly Forecast

Each row in the 72-hour forecast shows:

| Column | Description |
|---|---|
| Time | Hour of the day (12-hour format with AM/PM) |
| Icon | Weather condition symbol |
| Condition | Brief description (e.g., "Light Rain") |
| Precipitation | Chance of precipitation |
| Temperature | Current temperature in °F |

### Expanded Hourly Details

Tap any row to expand it and reveal additional detail:

| Detail | Description |
|---|---|
| Humidity | Relative humidity percentage |
| UV Index | Ultraviolet index |
| Feels Like | Apparent (feels-like) temperature in °F |
| Wind | Wind speed in mph |

Tap the row again to collapse the details.

---

## Weather Condition Icons

iShweather uses standard iOS weather symbols to represent conditions:

| Icon | Condition |
|---|---|
| ☀️ Sun | Clear |
| 🌤 Sun behind cloud | Partly or mostly cloudy |
| ☁️ Cloud | Cloudy / overcast |
| 🌦 Cloud with drizzle | Light rain or showers |
| 🌧 Cloud with rain | Moderate to heavy rain |
| ⛈ Cloud with lightning | Thunderstorm |
| 🌨 Cloud with snow | Snow |
| ❄️ Snowflake | Heavy snow or snowstorm |
| 💨 Wind | Windy |

## Troubleshooting

**The forecast won't load.**
Check that your iPhone has an active internet connection. Tap **Retry** on the error screen to try again.

**Search suggestions aren't appearing.**
Make sure you have an internet connection. The app fetches location suggestions from Google's Places service, which requires network access.

**Temperatures look wrong.**
All temperatures are displayed in Fahrenheit (°F).

---

## Privacy

iShweather does not collect or store any personal data. Location searches are sent to Google's Places API to provide autocomplete suggestions. Weather data is fetched from iShweather's backend server, which proxies requests to Google's Weather API. Your recent locations and preferences are stored only on your device.
